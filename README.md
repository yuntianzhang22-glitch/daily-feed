# Daily Feed

定期抓取你关注的 X 账号的帖子，整理成一个本地阅读流。支持 macOS 桌面端和 iPhone Safari 移动内测版。

## iPhone 内测（无需 Mac）

1. 在 iPhone 的 Safari 打开 [Daily Feed 移动版](https://daily-feed-reader.pages.dev)
2. 输入邀请人发给你的账号编号（`DF-XXXXX`），无需密码
3. 在「关注」选择想看的人，保存后点「立即抓取」
4. 可在 Safari 中点「分享」→「添加到主屏幕」，以后像应用一样打开

移动版支持阅读、搜索、来源筛选、收藏、已读、图片和视频，以及离线查看已保存正文。在「设置 → 定时抓取」选择每天、工作日或每周指定日期，以及北京时间；由云端执行，关闭手机页面后仍会运行。账号与额度和桌面端共用；手机再次打开时下载定时抓取的结果，收藏、已读与手动抓取内容仍保存在本机。需要可访问该 Cloudflare 服务的网络。

部署、邀请与验收说明见 [移动内测说明](docs/MOBILE.md)。

## 安装

1. 在 [Releases](../../releases/latest) 下载 `Daily-Feed-<版本>-mac-arm64.dmg`（Apple 芯片 Mac）
2. 打开 DMG，把 **Daily Feed** 拖到旁边的 **Applications（应用程序）**，然后从「应用程序」启动。若直接打开 DMG 中的应用，可点击「安装并打开」自动完成安装和重新启动
3. 第一次打开：右键点 Daily Feed →「打开」→ 再点「打开」。如果提示"已损坏，无法打开"，在终端运行：

```bash
xattr -dr com.apple.quarantine "/Applications/Daily Feed.app"
```

4. 未登录时启动会弹出登录窗口，输入账号编号（`DF-XXXXX`），或选择本机上次登录的账号，再点「登录」，无需密码
5. 点「关注」，从内置名单里勾选想看的人

安装完成后可以推出 DMG。首次安装或替换旧版时请先退出正在运行的 Daily Feed；自动安装在打开登录窗口和数据库前完成，已有登录和本机内容会保留。安装取消或失败时可重试或暂不安装。ZIP 文件供应用内更新使用。

之后的版本在应用内更新，配置、关注列表和帖子记录都会保留。数据存在 `~/Library/Application Support/Daily Feed/`。
启动约 5 秒后会检查更新，发现新版时弹出提醒；可立即更新或稍后，稍后仍可从侧栏或设置打开更新入口。

## 多设备登录

账号编号（`DF-XXXXX`）就是唯一登录凭证，新设备输入同一编号即可登录，无需密码或额外访问码。
在已登录设备的设置中点「复制账号编号」，即可在另一台设备使用；已有长凭证仍兼容。
未登录时启动显示独立登录窗口；上次登录的账号仅保存在当前设备，选择后仍须点击「登录」，并由服务端重新校验。
账号编号本身授予登录权限，请私下保管；停用会同时阻止编号与旧凭证登录。每次只记住最后一次成功登录的账号。
多台设备共用身份、余额和月额度；关注、收藏、已读、帖子和设置仍各自保存在本地，暂不跨设备同步。
退出登录只清除本机登录状态，保留本机内容。当前没有云端设备会话管理，停用账号会影响所有设备。

超管账号由服务端管理口令创建，登录后默认使用云端 API，无需在新电脑填写 API Key。超管不需要充值或用户月额度。
超管也可选择本机 API Key 直连，并在设置中切回云端；退出登录后不会因残留的加密 Key 自动恢复超管身份。
已有本机 Key 的旧超管仍可使用；创建独立账号后可在设置中登录该账号。

## 网络

应用使用系统代理设置。如果你的网络访问不了 Cloudflare（`*.workers.dev`），需要开启代理。

## 开发

需要 Node.js 24。在新电脑上克隆仓库后：

```bash
npm ci
npm run dev
```

打开的是与正式应用隔离的测试环境，内置合成帖子；在左侧验收面板切换超管、内测、付费身份，以及额度耗尽、余额不足、停用等状态。无需 API Key，不产生 API 费用。
超管、内测、付费用户都可用自己的账号编号在多台设备登录。三种身份共享同一份权限表：API Key、关键词和底层 API 成本只对超管开放，内测和付费用户只看到各自的账号、额度或余额。正式应用没有身份选择器。测试/预发中可以实际操作登录、复制账号、退出和重新登录，退出后重启仍保持未登录。左侧「复制样例账号编号」用于领取本地测试凭证；切换验收样例会装入该样例的账号与本地数据。
真实用户的登录、设置和错误提示不介绍其他身份或专属入口；内测账号只看到自己的额度，付费账号只看到自己的余额和充值说明。供应商故障统一提示服务暂不可用，不误报为用户需要充值。验收面板仅存在于隔离的测试/预发环境，业务界面使用与正式版相同的文案和权限。

- `npm run staging`：独立的预发验收环境
- `npm run staging:live`：显式配置自己的预发 API Key 后，联调真实抓取
- `npm run start:production`：正式服务和正式数据
- `npm test` / `npm run test:ui`：业务测试 / 后台运行的实际 Electron 页面验收，不弹窗或抢焦点
- `npm run release`：构建、验证并上传正式安装包及完整开发源码包到 GitHub
- `npm run dist:organize`：整理本机发布文件；当前版本留在 `dist/`，旧版本保留在 `dist/archive/`

完整的隔离规则、账号状态、真实 API 联调、远程预发部署和发布步骤见 [环境说明](docs/ENVIRONMENTS.md)。

- `desktop/`：Electron 应用（`core/` 是抓取、存储、配置、更新逻辑）
- `relay/`：Cloudflare 中转、账号账本、管理工具与部署配置（全部随仓库迁移）
- `dev/`：本地隔离服务、三类验收身份、合成数据和预发部署入口
- `test/`：单元测试、HTTP 集成测试和实际页面验收
- `build/package-mac.sh`：打包 .app、更新 zip 和 `latest.json`

安装包和开发源码包不含真实密钥或本地数据库。更换电脑后，样例验收可直接运行；正式服务管理和真实 API 联调的凭据需要从自己的密码管理器恢复。

帖子中文翻译的免费额度、独立环境配置和验收步骤见 [翻译说明](docs/TRANSLATION.md)。未配置 F0 时默认关闭真实翻译；本地测试使用标明样例的译文。

用户可在帖子下标记「有用 / 没帮助」，后端按账号记录、统计并支持研究数据导出，离线反馈保存在本机待同步。架构、权限、上线与统计命令见 [用户反馈说明](docs/FEEDBACK.md)。
