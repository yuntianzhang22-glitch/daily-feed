独立超管账号与多设备登录：

- 超管可和其他用户一样用独立的私密账号登录、复制账号、退出，并在新电脑直接使用云端 API，无需复制 API Key。
- 服务端管理口令独立负责创建超管，普通账号无法通过客户端字段或配置修改升级身份。
- 超管无需充值或用户月额度，保留关键词及成本配置；可选择本机 API Key 直连或切回云端。
- 兼容已有本机超管 Key；显式账号登录按所选账号运行，退出后不会被残留 Key 自动恢复成超管。
- 正式、测试、预发均覆盖三类账号的多设备登录与退出重启验收；本机内容暂不跨设备同步。
- 安装包与完整开发环境一并发布，真实账号凭证和密钥不进入 GitHub。
