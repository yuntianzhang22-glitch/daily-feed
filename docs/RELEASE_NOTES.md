Daily Feed 0.11.0：帖子反馈、移动端与关注管理更新

- 新增「有用 / 没帮助」标记，可切换、取消；支持离线待同步、同账号多设备反馈读取和重复上传去重。
- 反馈后端记录帖子及引用快照、互动数据、反馈历史与展示上下文，支持受保护的统计和数据导出；暂不自动改变推荐排序。
- 移动端支持按账号设置云端定时抓取、离线阅读和独立入口，并更新移动界面与关注批量操作。
- 桌面关注管理支持批量选择、取消、反选、清空、撤销与放弃修改。
- 桌面与移动端新增按需中文翻译入口和缓存；翻译服务暂未启用，配置 Azure Translator F0 后可开放。
- 账号权限、正式/预发数据和本地测试环境保持隔离；安装包不含管理员或供应商密钥。
- 提供 Mac Apple Silicon DMG 安装包、ZIP 更新包及包含客户端、服务端、测试/预发配置的完整开发源码包。
